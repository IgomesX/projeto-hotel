# Sistema de Reservas de Hotel

Projeto desenvolvido em TypeScript para praticar cinco padrões de projeto.

## Padrões utilizados

- **Factory Method:** criação das formas de pagamento.
- **Abstract Factory:** criação dos quartos e cafés da manhã.
- **Prototype:** clonagem de reservas existentes.
- **Singleton:** garante uma única instância de gerente.
- **Builder:** construção de contratos de hospedagem.
